# Smart Task Manager (Flutter)

Мобильное приложение для управления задачами, созданное в рамках задания курса AI-разработчик.

## Технологии
- **Фреймворк:** Flutter & Dart
- **Дизайн-система:** Material 3
- **CLINE** (AI-ассистент для кодинга)
- **Компонентный подход** (аналог React Native Expo)

## Функционал
- **CRUD и Мягкое удаление:** Полное управление задачами с возможностью отмены удаления через `SnackBar` (Soft Delete).
- **Категоризация и Фильтрация:** Разделение задач по категориям (Работа, Личное, Покупки) с использованием `Enum` и удобными `ChoiceChip` / `FilterChip` для фильтрации.
- **Умная сортировка и Анимации:** Выполненные задачи плавно меняют стиль (`AnimatedContainer`) и автоматически перемещаются в конец списка. Свайп для удаления (`Dismissible`).
- **Локальная база данных:** Асинхронное сохранение задач на устройстве с помощью `shared_preferences` и сериализации в JSON.
- **Многостраничность и Навигация:** Разделение UI на логические экраны с использованием `BottomNavigationBar` и `IndexedStack` для сохранения состояния страниц.
- **Mock-Авторизация:** Экран входа по PIN-коду для защиты приложения.
- **Дашборд статистики:** Визуализация продуктивности в реальном времени с круговым графиком прогресса.

## Структура проекта
- `lib/models/` — сущности данных.
- `lib/screens/` — основные экраны (аналог `src/screens` в Expo).
- `lib/widgets/` — UI-компоненты (аналог `src/components`).
- `lib/controllers/` — классы стейт-менеджмента (TaskController), отвечающие за обработку данных, сортировку и связь с хранилищем.
